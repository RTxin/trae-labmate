## 1. 产品概述

**一句话**：装在研究者本机 IDE 里的科研 AI 搭档——先把专家没说出口的参数问出来（引导协议），再用确定性工具把活干完（计算引擎 + 文献 + 数据）。

**定位（来自市场空白）**：现有 AI 科研产品（NotebookLM、Elicit、SciSpace、Consensus、scite、Jenni 等）全部围绕"文献"环节、全部云端、全部要求用户会提问。而研究者时间的大头——**试验 20-25% + 数据分析 15-20%——以及"AI 新手引导"环节，无人覆盖**。LabMate 的差异化：本地优先、对话引导、确定性计算工具、面向不会用 AI 的领域专家。

## 2. 调研结论摘要（本次升级的依据）

### 2.1 用户时间与信任数据
- 时间分配（your.phd 2023-24 汇总）：文献阅读 25-30% ＞ 试验/采集 20-25% ＞ 数据分析 15-20% ＞ 写作 15-20% ＞ 行政 10-15%
- Nature 研究生调查 2025（n=3785）：**60% 接受 AI 总结文献**（最高），仅 **33% 接受 AI 分析数据/写论文**（最低）——数据类任务需要"引导式低风险交互"来建立信任
- 2400 科学家调查：最大顾虑是**幻觉/编造文献**；Springer Nature：最大挑战是"披露差距"

### 2.2 试验学科（力学/材料/物理）特有痛点
- 仪器厂商专有二进制格式，元数据需逆向（arXiv 2511.01942）
- 数据滞留"本地笔记本/仪器文件夹"，Excel 中心工作流的转录错误与溯源断裂（Bassetti）
- 单次声发射试验数十万波形，人工处理不可行（Frontiers）
- 领域专家普遍缺编程能力（arXiv 2511.21920）——与 P1 画像完全吻合

### 2.3 工具生态查证（适合集成的排序）
| 方向 | 查证结论 | 集成方式 |
|---|---|---|
| arXiv 检索 | 官方 API **完全免费、无需 key**、Atom XML | **API 封装进 MCP server（P0）** |
| Crossref/DOI | 官方 API **免费无 key**（mailto 即 polite） | **API 封装：DOI→元数据→BibTeX（P0）** |
| SciencePlots | 本质是 .mplstyle 样式字典（IEEE/Nature/科学风） | **自研内置样式注入（P0）** |
| handcalcs | 符号替换+排版模板，核心可零依赖复刻 | 已自研（labmate_handcalc），P1 增强 LaTeX 输出 |
| 多源文献聚合 | paper-search-mcp（3.1k★ arxiv-mcp 同作者）思路：多源并发+去重 | P2（先单源做稳） |
| Zotero/pandoc | 依赖用户本地环境 | skill 指导（P2） |

## 3. 用户画像

**P1 资深研究者·领域专家（主画像）**——"能力极强的提问弱者"
- 特征：脑内知识完整（装置、工况、经验参数），但不会把它显性化；把 AI 当聊天框；对计算结果要求可校核
- 关键句："今天的 AI 没一个能打的"——真实原因是输入缺了 80% 隐含前提
- 需求：引导协议把参数问出来；教科书式计算过程；量级校核先于细节

**P2 博后/青年教师**——"效率优先的多面手"
- 时间被试验、数据、写作、基金本子撕碎；愿意用工具但没空学
- 需求：数据快速处理（CSV→统计→图）；文献快速侦察（arXiv 新论文）；投稿物快速产出（图表/引用）

**P3 博士生**——"AI 重度但方向迷茫"
- 愿意折腾，但缺乏领域量级感，容易被 AI 的自信误导
- 需求：诚实的不确定性标注；公式推导可验证；红线警示（"设备吨位不够"这类工程判断）

## 4. 用户旅程与痛点矩阵

```
读文献(25-30%) → 做试验(20-25%) → 处理数据(15-20%) → 分析论证 → 写作(15-20%) → 投稿/披露
```

| 环节 | 痛点 | 现有竞品 | LabMate 0.1 | 升级动作 |
|---|---|---|---|---|
| 读文献 | 单篇精读 30-40min；综述准备占 50-70% 时长 | 云端全覆盖 | 无 | **P0：arXiv 检索工具** + P1 精读 skill |
| 引用管理 | 手编 BibTeX 格式错；引用真实性焦虑（幻觉文献） | scite 验真（云端） | 无 | **P0：DOI→BibTeX（真实元数据，杜绝编造）** |
| 试验设计 | 隐含前提说不出口；设备/方案可行性靠拍脑袋 | 无 | consult 模块 ✓ | 保持 |
| 数据处理 | Excel 转录错误；仪器格式；缺编程能力 | **无人覆盖** | data skill（指导性） | **P0：labmate_table 本机数据工具**（零依赖 CSV 读取+统计摘要） |
| 分析计算 | 黑箱结果不可信（33% 信任率） | 无 | handcalc/mohr/fit ✓ | 保持 + P1 LaTeX 输出 |
| 写作出图 | 图不像期刊的；样式调半天 | 部分写作产品 | plot skill（指导性） | **P0：期刊样式注入工具** |
| 披露合规 | AI 使用声明的"披露差距" | 无 | 无 | P1：输出校验 + 声明模板 |

## 5. 竞品分析结论

九款产品（NotebookLM/Elicit/SciSpace/Consensus/scite/ResearchRabbit/Connected Papers/Jenni/Iris.ai）功能矩阵表明：
- **文献环节**：发现、图谱、综述、接地问答、写作、引文验证全部成熟——**不正面竞争**
- **空白 1**：本机试验数据（读取/清洗/统计/绘图）——LabMate 独占
- **空白 2**：AI 新手引导（参数结构化）——LabMate 独占（consult 协议）
- **差异化 3**：本地优先（数据不出机器）vs 全员云端——对涉密/未发表数据的研究者是硬需求

### P3（0.4.0 · 需求复核后实施：17 工具 / 15 skills）

**复核结论**：对照科研人员时间分配数据（文献 25-30% / 写作 20-25% / 数据分析 15-20% / 实验设计 15-20% / 行政 10-15%），v0.3 的 P0-P2 视野集中在"文献+计算"，六类高频刚需完全空白：统计推断、不确定度评定、实验设计、论文写作生成、BibTeX 库管理、试验曲线信号处理——"功能太少"的用户反馈成立。0.4.0 用 6 个零依赖新工具补齐，每个都有明确的时间占比依据：

| # | 工具 | 覆盖刚需 | 零依赖实现要点 |
|---|---|---|---|
| 12 | `labmate_stats` | 数据分析 15-20%（显著性/样本量是试验论文审稿刚需） | 正则化不完全 Beta（Lentz 连分数）实现 t/F 精确 p 值；不完全 Gamma（级数+连分数）实现卡方；Lanczos lnΓ；输出 Cohen's d / η² 效应量优先 |
| 13 | `labmate_errors` | 数据分析（GUM 不确定度是测试报告/学位论文法定章节） | AST 公式 + 中心差分数值偏导 + 一阶合成 + k=2 扩展；OLS 斜率截距 t 区间 |
| 14 | `labmate_doe` | 实验设计 15-20%（正交表是三/四因素试验的标准答案） | GF(p) 素数域生成 L4-L32/L9/L27/L25（正交性有数学保证，可程序化验证），而非硬编码 Taguchi 表 |
| 15 | `labmate_tex` | 写作 20-25%（三线表/图环境是投稿高频机械劳动） | booktabs 规范、CSV 直读、数值列自动右对齐、多图自动 subfigure |
| 16 | `labmate_bibtex` | 写作（多库合并/重复引用是合作写稿的常态痛苦） | 花括号配平解析、DOI 优先+标题兜底去重、字段互补合并 |
| 17 | `labmate_signal` | 数据分析（试验曲线去噪/积分/重采样） | Savitzky-Golay 闭式系数（解 (AᵀA)z=e₀，复用高斯消元）、Simpson 精确积分 |

**新增 skills**：`labmate-stats`（方法选型表 + p 值误用防护六条军规——多次比较校正、效应量优先、JB 小样本局限、样本量事前算）、`labmate-writing`（数据→三线表→图→bib 库→disclosure 的投稿标准工作流 + LaTeX 排版共识）。

**独立代码审查修复 8 个 bug**（108 项旧测试全绿仍有漏网，证明"测试通过≠实现正确"）：
1. `_latex_expr` 负号括号：`-(a+b)` 曾渲染为 `-a + b`（公式与计算结果矛盾）
2. Mohr `phi=0`（不排水黏土 τ=c 包络）被 falsy 判断静默跳过
3. 欧式 CSV（分号分隔+逗号小数）分隔符误判
4. `float("1,5".replace(",",""))` → 15 的欧式小数灾难（新增 `_parse_cell_float` 按正则区分千分位/欧式）
5. BibTeX 标题含 `%` 截断条目、`&#_` 致 LaTeX 编译错（新增 `_tex_escape`）
6. 同年同作者 BibTeX key 撞车（`used_keys` 自动 a/b 后缀，默认 key 格式保持兼容）
7. 卡方分布连分数分支 `c` 初值错误导致 df=1 时 p 值爆炸为 1e297 量级（0.4.0 编码期引入，v04 已知值测试当场抓获）
8. Savitzky-Golay 系数矩阵行变量名错误（NameError，同上当场抓获）

验收：四套单测 194 项全绿（v04 新增 86 项已知值对表验证：χ²=3.84→p=0.05、F(3,12)临界值、√2 单样本 t、Simpson x³ 精确积分、L8 正交性穷举、LHS 分层性等）。

### P4（0.4.1 · 数据入口补强：Excel 直读）

**复核结论**：调研 2.2 已指出"试验数据滞留本地仪器文件夹，**Excel 中心工作流**的转录错误与溯源断裂"（Bassetti）——但 0.4.0 的 `labmate_table` 只吃 CSV，而科研试验数据的一大半躺在 .xlsx 里。数据进不来，table→stats→fit→plot 整条链路都白搭。这是"用户数据进不来"的硬卡点，优先级高于一切新分析功能。

**方案**：不新增工具，`labmate_table` 增加 `xlsx_path` + `sheet` 参数；内部新增 `_read_xlsx` 产出 `(header, rows)` 后**完全复用既有统计链路**（`_table_summary`/`_parse_cell_float`）。坚持零依赖（zipfile + ElementTree 手工解析 OOXML，与 PDF 的 zlib 方案同思路），不引入 openpyxl。

**ECMA-376 已知坑位全处理**（每条都有 fixture 断言守护）：
| # | 坑位 | 处理 |
|---|---|---|
| ① | 空单元格在 XML 中直接缺失 → 列错位 | 按 `<c r="B3">` 列字母定位，稀疏行补空字符串 |
| ② | t="s" 共享字符串 | 查 sharedStrings.xml，富文本 `<r><t>` 段落拼接（跳过注音 rPh） |
| ③ | 字符串形态分叉 | inlineStr 读 `<is><t>`；布尔 t="b" 转 TRUE/FALSE；公式文本 t="str" 直取 |
| ④ | 日期是序列号 + styles.xml 数字格式 | 内置 numFmtId 14-22/45-47 + 自定义 formatCode 判定；1900 系统伪闰年分两段起点（serial≥61 用 1899-12-30），转 ISO 文本 |
| ⑤ | 第一个 sheet 文件名不保证 sheet1.xml | 解析 workbook.xml + rels 的 rId→target 映射 |
| ⑥ | 数值科学计数 `1.5E-3` 被当文本 | `_parse_cell_float` 增加科学计数分支（CSV 同样受益） |

**验收**：五套单测 234 项全绿（v05 新增 40 项：fixture 用 zipfile 现场构造标准 xlsx——双工作表、第一个 sheet 故意命名 zz9.xml、稀疏空位、富文本、三种日期样式、科学计数；坏文件边界覆盖老式 .xls 引导另存、纯文本伪装、缺 workbook.xml、只有表头；CSV 老路径全回归）。

### P5（0.4.2 · 数据链路闭环：绘图与曲线特征，19 工具）

**复核结论**：P4 打通了"数据进得来"（CSV/xlsx 直读），但研究者工作流的终点是**图**和**特征值**——前者进论文，后者进正文与报告。0.4.2 前的缺口：① `labmate_style` 只给 matplotlib 样式参数，用户没装科学栈时依然出不了图；② 弹性模量、0.2% 偏移屈服这类力学试验的标准特征值，用户只能手工作图量取（Excel 中心工作流的转录错误高发区，见调研 2.2）。补上这两环后，"xlsx 直读 → stats 统计 → curve 特征 → plot 出图"的**本机试验数据全链路**在零依赖前提下闭环。

| # | 工具 | 覆盖刚需 | 零依赖实现要点 |
|---|---|---|---|
| 18 | `labmate_plot` | 写作出图（15-20% 时间占比的"结果→可发表片段"环节） | 纯手写 SVG（沿 Mohr 圆先例）：白底黑字衬线、1-2-5 优雅刻度、对数轴（10 幂 + 2×/5× 中间刻度）、双组对比、误差棒端帽、图例框；>800 点自动抽稀且明示；save_path 直接落 .svg 文件 |
| 19 | `labmate_curve` | 力学试验标准特征值（E、屈服强度是拉伸/压缩报告法定指标） | 弹性段窗口线性回归（复用 `_polyfit`）+ R²；0.2% 偏移线与曲线首个交点线性插值（偏移量可调适配 0.1%/0.05% 标准）；峰值/末点；总能量 Simpson（等距偶数段）/梯形自动选择；脆性无平台诚实报"未找到" |

**验收**：六套单测 292 项全绿（v06 新增 58 项：合成"线弹性 E=200 + 理想塑性平台"曲线手工可算——E=200、屈服 (0.004, 0.4)、Simpson 能量 0.002 精确命中；SVG 结构断言（viewBox/polyline/误差棒端帽/图例框/对数刻度）；边界覆盖长度不等、log 轴负值、x 重复、无屈服交点、`or` 吞零值参数两处拦截）。

### P6（0.4.3 · 报告级最后一环：分组柱状图与平行试样批量，仍 19 工具）

### P7（0.4.4 · 强度统计报告的法定动作：异常值剔除与 Weibull 分析，仍 19 工具）

**复核结论**：P6 补齐了"图与批量"，但强度数据的两个法定报告动作仍空白：① 异常值剔除是 GB/T 4883 规定的报告前置步骤——物理原因不明的极端值不能凭感觉扔，审稿人会问依据；② 脆性材料（陶瓷/岩石/混凝土/玻璃）的强度散点服从 Weibull 分布，**模数 m 与特征强度 σ₀ 是审稿必问指标**，审稿人看到"均值±标准差"汇报脆性强度会直接质疑统计口径。0.4.4 不新增工具，两法都挂 `labmate_stats`（统计方法集心智一致），至此"xlsx 直读 → outlier 剔异常 → stats/weibull 统计 → plot bar 出图"的**强度试验报告全链路**闭环。

| # | 增强 | 覆盖刚需 | 零依赖实现要点 |
|---|---|---|---|
| 12+ | `labmate_stats` 加 `action=outlier` | GB/T 4883 异常值检验（报告法定前置） | 格拉布斯双侧临界用 Grubbs & Beck 1972 精确式由 `_t_ppf` 现算（与教科书表值 1.153/2.020 吻合，无硬编码表）；狄克松内置国标 D(α,n) 表（n=3~30，r10/r11/r21/r22 四段公式随 n 自动切换）；**歧离值（α=0.05 检出）与统计离群值（α=0.01 剔除）两级判定**；迭代剔除逐轮重查临界值，剔除超 1/10 警惕测量系统问题 |
| 12+ | `labmate_stats` 加 `action=weibull` | 脆性材料强度 Weibull 统计（审稿必问 m 与 σ₀） | 中位秩（Bernard F_i=(i-0.3)/(n+0.4)）线性化 lnln(1/(1-F)) = m·ln σ − m·ln σ₀，复用 `_polyfit` 最小二乘；输出模数 m、特征强度 σ₀、线性化 R²、B10 强度；可选 stress 参数返回破坏概率（σ=σ₀ 处恒 63.2%，定义自检） |

**验收**：八套单测 409 项全绿（v08 新增 54 项：格拉布斯临界双锚点对教科书表 n=3→1.153（柯西解析可手算）与 n=7→2.020；完美 Weibull 样本（m=8、σ₀=500 由中位秩公式反解生成）回归**精确还原三参数**；狄克松 r 公式四段手算对表；格拉布斯两轮迭代剔除（极端值先剔除以暴露次极端值）；歧离值保留、低端方向、无波动诚实停止、10 项边界拦截）。无新 bug；测试数据构造教训：n=7 双侧 0.01 临界高达 2.355，两个温和异常值互相掩护时 G 卡在 2.0 附近不显著——多异常场景必须"极端值先出局"后次极端值才暴露，这正是迭代剔除逐轮重查临界值的意义。

### P8（0.4.5 · 振动测试标准动作：FFT 频谱与固有频率，仍 19 工具，skills 15→16）

**复核结论**：P2 曾记录「振动领域模块按需复制 TEMPLATE」，本轮触发条件成熟：力学/机械试验的振动测试（锤击法、加速度时程、自由衰减）需要频域分析，而 0.4.4 前的 labmate_signal 只有时域动作（平滑/插值/积分/重采样）——**FFT 是信号处理的最后一块标准拼图**。没有它，"采样率怎么定、固有频率是多少、混叠了没有"这三个振动测试最常见的问题无法在本机闭环，用户只能把数据拖去 MATLAB。0.4.5 不新增工具，`labmate_signal` 加 action=spectrum；同时按 TEMPLATE 复制 `labmate-vibration` 领域模块，承接"领域专家默认知道但通用 AI 常缺"的振动专业常识（采样定理 2.56× 工程系数、Δf=1/T 是时长问题、混叠不可逆、半功率带宽阻尼）。

| # | 增强 | 覆盖刚需 | 零依赖实现要点 |
|---|---|---|---|
| 17+ | `labmate_signal` 加 `action=spectrum` | 振动/声学时程的频域分析（固有频率识别是结构试验标准动作） | radix-2 迭代 FFT（位反转置换+蝶形合并，O(N log N)）纯手写；非二次幂自动零填充至下一 2^k 并在标题明示；单边幅值谱（k=1..half-1 幅值×2 折叠，直流与 Nyquist 不翻倍）；输出 Δf=fs/N、Nyquist、直流（均值）、主峰局部极大降序前 5（1% 幅值阈值滤噪声地板） |
| 新 skill | `labmate-vibration` | 振动领域引导（第 16 个 skill） | 复制 TEMPLATE：采样方案制定、频谱解读、泄漏与整周期、阻尼半功率带宽、模态分析超界声明；**零新增依赖**（FFT 已内置于 spectrum） |

### P9（0.4.6 · 疲劳数据法定动作：S-N 拟合与寿命预测，仍 19 工具）

**复核结论**：P7 的 outlier/weibull 打开了"强度数据法定报告动作"的先例，疲劳试验的同款标准动作是 S-N 曲线：轴向疲劳/旋转弯曲试验的 (应力, 寿命) 数据要拟合成 Basquin 方程 σᵃ·N=C，再按工作应力反算寿命——这是疲劳报告的法定内容，此前用户只能手工作图或拖 Excel（正是调研 2.2 指出的转录错误高发区）。0.4.6 不新增工具，`labmate_stats` 加 action=sn（与 outlier/weibull 并列，同属"强度数据法定报告动作"心智），完全复用现有 `_polyfit` 一阶回归与 weibull 的 R² 算法，零新数学代码路径。

| # | 增强 | 覆盖刚需 | 零依赖实现要点 |
|---|---|---|---|
| 12+ | `labmate_stats` 加 `action=sn` | 疲劳试验报告法定动作（S-N 曲线拟合 + 给定应力寿命预估） | Basquin σᵃ·N=C 双对数线性化（x=ln σ、y=ln N，一阶回归：a=−斜率、C=e^截距）；target_stress 给定应力预测 N=C·σ^(−a)，超出试验范围明示"外推仅供量级参考"；边界全拦截：等长/全正（ln 定义域）/n≥3/传反（a≤0，寿命随应力升而升即数据不成立）/退化（无波动）；量级感内建（钢典型 3~10、铝合金 5~15，异常先查数据）；runout（未断试样）不能混入的专业警示与适用域（中高周 10³–10⁷，低周走 Coffin-Manson 应变法） |
| skill 补充 | `labmate-fracture` 加 S-N 行 + 主路由加行 | 疲劳领域引导闭环 | 核心任务表加"labmate_stats action=sn"行，与 Paris/临界裂纹并列成完整疲劳评估链（裂纹起始寿命走 S-N，扩展寿命走 Paris） |

**验收**：十套单测 487 项全绿（v10 新增 36 项：黄金用例 C=1e12、a=3 精确反解——N=C·σ^(−a) 零噪声构造，回归**精确还原 a=3/C=1e12/R²=1，预测 σ=250 → N=64000 cycles 精确**（1e12/250³ 手工可验）；确定性 ±3% 扰动 6 点用例 a 还原 5.01477、R²=0.999886；边界十四项：缺 stress/缺 cycles/不等长/n<3/应力含 0/寿命含负/传反/退化/target_stress≤0/外推明示/未知 action 尾串/weibull 旧路径不受影响（stress 单值语义两用））。一次通过无返工。

### P10（0.4.7 · 多因素分析默认答案：多元线性回归，仍 19 工具）

**复核结论**：试验数据的多因素问题（强度 ~ 水胶比 + 龄期 + 掺量；变形 ~ 温度 + 围压）此前只有两条路——逐个单因素 fit_lite（丢信息，无法判定"哪个因素真的重要"）或装 numpy/lmfit（对零依赖开箱即用的定位是断崖）。而"哪个因素显著、各占多少、模型该留几个变量"正是审稿人必问、报告必写的标准动作。0.4.7 不新增工具，`labmate_fit_lite` 加 `model=multi`（与 linear/poly/power/exp 并列）：x 支持按变量分组（与 stress/cycles 平行传参惯例一致）或按样本分行（自动转置），一维退化为单自变量；系数 t 检验复用 stats 的 `_t_sf` 精确尾概率、整体 F 复用 `_f_sf`——零新分布代码。底层从 `_polyfit` 提取 `_gauss_solve` 列主元消元（行为等价重构，487 项历史测试守护），正规方程与逆矩阵用增广 [XᵀX | Xᵀy | I] 一次消元同解（右端经历同一行变换，置换自动抵消）——零重复数值逻辑。

| # | 增强 | 覆盖刚需 | 零依赖实现要点 |
|---|---|---|---|
| 4+ | `labmate_fit_lite` 加 `model=multi` | 多因素试验标准分析（因素显著性/变量取舍/模型比较） | OLS 含截距；x 两种形态自动对齐（按变量分组优先；行数 = n 且各行等长时转置）；系数表含 t/p/显著标注（p<0.05）、调整 R² = 1−(1−R²)(n−1)/(n−p−1)（惩罚多余自变量）、整体 F、残差标准误 s；边界全拦截：共线（x2=2x1 奇异）、样本量不足（n<p+2）、形态无法对齐、非数值、y 无波动（R² 无定义明示）；n<5p 样本量偏少警示；完美拟合（s=0）不做 t 检验（检验无意义，诚实明示） |
| skill 补充 | `labmate-fit` 加零依赖通道提示 + 主路由加行 | 引导闭环 | fit skill 开头"先查零依赖通道"：多元线性回归不必装 lmfit 直接走 multi；lmfit 留给非线性本构/物理边界/参数不确定性 |

**验收**：十一套单测 533 项全绿（v11 新增 46 项：黄金用例 y=2+3x₁−0.5x₂ 零噪声**精确还原 b0=2/b1=3/b2=−0.5/R²=1**；确定性 ±0.05 扰动用例全参数固化断言——b0=2.02371/b1=2.98935/b2=−0.494291/R²=0.999923/**调整 R²=0.999872（=1−(1−R²)·5/3 手工可验）**/F=19570.6/s=0.0529429；按行自动转置与按列传参结果一致；无关变量判"不显著"（p=0.342245）；共线/样本不足/形态/非数值/y 无波动边界；`_gauss_solve` 多右端列数学断言（A⁻¹ 两列一次解出）；`_polyfit` 重构等价性；协议层与 stdio 冒烟）。一次通过无返工。

工具分组原则：**确定性可复现的进 server，需要判断力/上下文的进 skill**。

---

## 8. 非功能需求

1. **零第三方依赖**：server 必须在裸 Python 3.8+ 上运行；科学栈（numpy 等）仅作为可选增强
2. **离线降级**：网络类工具（arxiv/cite）失败时返回诊断 + 缓存建议；其余工具完全离线可用
3. **数据不出本机**：所有工具本地执行，无遥测；`labmate_table` 只读不写
4. **安全求值**：handcalc 保持 AST 白名单；网络工具的超时与响应大小限制
5. **中文与编码**：Windows GBK 控制台保护（reconfigure utf-8）已在 0.1 实现，保持

## 9. 验收标准

- 全量单测（含 4 个新工具各 ≥4 用例）通过；stdio 冒烟含 tools/list = 9
- `labmate_arxiv`：真实网络查询返回论文（离线时返回可读诊断）
- `labmate_cite`：真实 DOI（10.1038/nature...) 返回规范 BibTeX；错误 DOI 给明确提示
- `labmate_table`：对含缺失值/混合列的 CSV 正确输出统计；中文文件名
- `labmate_style`：4 种样式返回参数字典且可写 .mplstyle 文件

- 工具可复现：同一输入跨次调用结果一致（确定性）
- 扩展成本：新领域模块按 TEMPLATE 从 0 到可用 ≤ 30 分钟
