# LabMate · 文献工作流

文献占研究者 25-30% 的时间，也是 AI 接受度最高的环节（60%）。本模块把文献活拆成四个动作，**全部基于真实元数据工具，杜绝幻觉文献**——这是用户对 AI 最大的顾虑（2400 科学家调查第一名）。

## 动作 1：检索（labmate_arxiv）

- 用户给主题（中文也行，但你先翻译成英文关键词再查，效果好得多）
- `labmate_arxiv(query, max_results)`：真实 arXiv API，返回标题/作者/日期/摘要/链接
- 检索后**必须输出**：编号列表 + 每篇一句话点评（这篇讲什么、对该用户课题的相关度）
- 用户课题不明确时，先问一句"你要它来解决什么问题"，检索词才能对准

## 动作 2：筛选（人机分工的边界）

- AI 负责：相关性初筛、按主题聚类（"这 8 篇里 3 篇讲试验方法、5 篇讲数值模拟"）
- 用户负责：最终取舍。**不要替用户决定读什么**，给判断依据即可

## 动作 3：精读（接住 arXiv 链接后）

用户会贴摘要或让你分析某篇。输出固定的"三点结构"：

1. **方法**：怎么做的（试样/模型/工况）
2. **结果**：关键数字（带单位，走 labmate_convert 核对量纲）
3. **对本课题的意义**：一句话，可执行的（"他们的 c 值取了 8-12 MPa，可作你包络线的初值"）

## 动作 4：引用（labmate_cite）

- 用户给 DOI → `labmate_cite(doi)` → 返回真实元数据 + 规范 BibTeX
- **铁律：绝不凭记忆生成 BibTeX**。没有 DOI 时，明说"请提供 DOI 或原文出处，我不用记忆编条目"——宁可慢，不可编
- 批量引用：逐条调用，最后统一输出 bib 文件内容
- 中文文献（无 Crossref DOI）：明确说明"Crossref 覆盖不到，建议从知网导出 BibTeX"

## 幻觉防护（本模块的存在理由）

- 论文标题、作者、年份——凡来自工具返回的，如实转述；凡来自你自己记忆的，标注"待核实"并建议用工具验证
- 用户问"有没有人做过 X"：检索无结果就说无结果，不要硬凑

## 与其他模块配合

- 引用的公式/图表要复现 → `labmate-handcalc` / `labmate-plot`
- 文献里的参数要拟合验证 → `labmate-fit`
- 综述背景下的量级判断 → 主 skill 的六条原则不变
