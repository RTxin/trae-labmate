# LabMate · 统计分析与实验设计（labmate-stats）

计算引擎已内置零依赖精确 p 值（不完全 Beta/Gamma 连分数实现，与 scipy 对表验证），**不要现场手写统计脚本，直接调工具**：

| 需求 | 调用 |
|---|---|
| 描述统计 / t 检验 / ANOVA / 正态性 / 置信区间 / 样本量 | `labmate_stats`（action: describe/ttest/anova/normality/ci/power） |
| GUM 不确定度传播 / 回归参数 95%CI | `labmate_errors`（action: propagate/regress） |
| 正交表 / 全因子 / 拉丁超立方 | `labmate_doe`（action: ortho/fullfact/lhs） |

## 方法选型（先问设计，再选检验）

| 用户的数据形态 | 正确方法 | 常见误用 |
|---|---|---|
| 一组数据 vs 已知标准值 | 单样本 t（ttest 只给 a + mu） | ❌ 用 3σ 规则替代检验 |
| 两组独立样本 | Welch t（默认，不等方差也稳） | ❌ 不问设计直接上 Student t |
| 同一试样处理前后/平行对照 | 配对 t（paired=true，**必须等长**） | ❌ 配对数据按独立样本做（丢失功效） |
| 三组及以上 | ANOVA + 事后比较 | ❌ 多组间两两 t（放大Ⅰ类错误） |
| 方差/协方差分析、非正态重尾数据 | 本工具边界外，建议 scipy.stats / statsmodels | ❌ 强行 t 检验 |

**选型前必问三件事**：①几组数据？②独立还是配对？③想证明"有差别"还是"等价"？——第③问多数用户没想过。

## 本领域的专业常识（统计误用防护，模块的灵魂）

1. **p > α ≠ 两组相同**。只能写"未检出显著差异"，不能写"无差异"；样本量不足时 p 值什么都证明不了。相应地，**先报效应量（Cohen's d / η²，工具已输出），再报 p 值**——审稿人越来越只认效应量。
2. **p 值操纵红线**：多次比较必须 Bonferroni 校正（工具的 ANOVA 输出已提示组对数）；不许"收集数据到 p<0.05 为止"；不许事后删"异常值"再检验——删除任何数据点必须报告并说明理由。
3. **正态性检验的局限**：Jarque-Bera 在 n<30 时功效低——"未拒绝正态"不等于"正态"；n>30 时它又几乎总拒绝（大样本对偏差极度敏感，而这点偏差对 t 检验稳健性无关紧要）。结论：n<8 拒绝做、8≤n<30 结果仅供参考、大样本看 Q-Q 图说话。
4. **样本量是事前算的，不是事后补的**：power 计算输入三件套——想检出的最小差异 δ（由工程意义定，不是拍脑袋）、合并标准差 sd（查文献或做预试验）、目标功效（惯例 0.8）。写基金/开题时先算，别做完试验才发现每组 3 只样品什么也证不了。
5. **不确定度 ≠ 标准差 ≠ 误差限**：单次测量的分散性给标准差；最终结果报告给扩展不确定度 U（k=2，约 95% 置信）。GUM 一阶传播忽略高阶项与输入相关性——输入强相关时须人工加协方差项，工具输出已提示。
6. **正交表的"空列"不是浪费**：空列用于估计试验误差，做 F 检验的误差项；因素多于列数时先筛选后细化（8 次运行的 L8 筛 7 个因素，显著的再上 L16/L32 细化）。

## 典型工作流

**试验数据显著性判断**：
```
labmate_stats(normality, data=残差或原数据)   # 前提检查（结果仅供参考）
labmate_stats(ttest, a=试验组, b=对照组)       # Welch 默认；配对设计加 paired=true
→ 报告顺序：均值差 → 效应量 d → p 值 → 工程意义解读（差异虽显著但幅度小于测量不确定度时要直说）
```

**不确定度评定**：
```
labmate_errors(propagate, formula="F/(pi*d*t/4)", vars={...}, uncertainties={...})
→ 报告 u_c、U(k=2) 与各分量贡献占比 → 贡献 <10% 的分量直接说"可忽略"，别堆数字
```

**正交试验设计**：
```
labmate_doe(ortho, runs="L9")    # 3 水平 4 因素
→ 把可控因素排前几列，空列留作误差估计；重复试验 ≥2 次分离失拟与纯误差
```

## 与其他模块的配合

- 数据清洗后才做统计（先走 `labmate-data`：去噪、去异常、列确认）
- 试验方案的前置咨询走 `labmate-consult`（补全设备/试样/参数）
- 统计结果进论文 → `labmate-writing`（三线表），显著性表述过 `labmate-disclosure` 校验
- 需要分布之外的检验（非参数、混合模型、Bayesian）→ 诚实说"超出零依赖工具边界，建议 scipy.stats/statsmodels"，并给出具体函数名
