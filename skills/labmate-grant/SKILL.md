# LabMate · 基金申请书写作引导（labmate-grant）

> 覆盖场景：NSFC 青基/面上为主的申请书结构引导、评审视角把关、与 LabMate 计算工具链的衔接。纯引导模块，零依赖零新工具。

基金本子是学术圈年复一年的最高频长文写作，而落选本子的死法高度重合——本模块把这些死法列成清单，把每一节的"评审人真正在看什么"写明白。

## 开写前的四问协议（先问后写，与试验咨询同款精神）

用户说"帮我写本子"时，脑中已有 80% 背景没说出来。动笔前必须把四问问出来（用户答不上的那问，就是本子最薄弱的地方）：

1. **科学问题是什么**——用一句话说清"申请什么问题的答案"（不是"做什么事"）。用户卡壳时给对照：*揭示 X 在 Y 条件下的 Z 机理*（问题）vs *搭建 X 试验平台*（任务）。
2. **为什么是你**——你过去哪 2~3 项工作直接支撑这个问题？这些工作就是研究基础的主干，不是论文清单堆砌。
3. **为什么是现在**——领域里刚发生了什么（新现象/新方法/新数据）让这个问题现在能做而三年前不能？这就是立项依据的"钩子"。
4. **为什么这样做**——方案里每一步与科学问题的映射关系。答不上映射的那一步，就是评审人要砍的那一步。

四问齐了再进结构写作。

## 申请书结构表（每节的"评审人真正在看什么"）

| 节 | 写作要点 | 评审人在看 |
|---|---|---|
| 立项依据 | 漏斗结构：国家需求 → 领域现状 → 研究缺口 → 引出科学问题。现状综述必须落到"缺口"上收口 | 缺口是否真实存在、逻辑链是否闭合；只综述不收口 = 没有立项理由 |
| 研究目标 | 一段话，量化可验收（"阐明…、建立…、获得…"），与研究内容一一呼应 | 目标是否可验收，还是口号 |
| 研究内容 | **3 条左右黄金结构**：每条一个完整科学单元（机理—方法—验证），条数过多必散、过少必单薄 | 内容与目标的映射；是否覆盖了全部目标又不超出目标 |
| 关键科学问题 | 1~2 个，写"问题的卡点"（为什么现在还没答案），不是写任务 | 是科学问题还是工程任务——这是最常见的死穴 |
| 研究方案与技术路线 | 方案讲"每条内容怎么做"，路线图讲"步骤间如何衔接与闭环"；关键步骤给备选路径（风险预案） | 路线图是否真能回答科学问题；无备选 = 无风险意识 |
| 可行性分析 | 三段式：理论可行（原理）+ 条件可行（设备/材料/数据已有）+ 人员可行（前期积累） | 有没有"虚"：没设备说有设备是大忌 |
| 特色与创新 | **2~3 条**：科学思想/科学方法创新，每条一句话说透；"使用了新设备/新软件"不是创新 | 创新是"思想"还是"采购" |
| 研究基础与工作条件 | 直接相关的 2~3 项代表作 + 与本项目的关联证据；条件写实际拥有的 | 人与项目的匹配度 |

## 评审视角常识（模块的灵魂）

1. **每本本子的阅读时间以分钟计**：函评/会评专家面对几十本，首段、关键科学问题、路线图三处决定第一印象。把最好的一句放在立项依据第一段的最后一句。
2. **"研究内容是任务清单"是第一大死因**：出现"采购、搭建、参加会议"式内容直接降档——所有内容必须是"回答科学问题的步骤"。
3. **创新点忌多忌空**：写 4~5 条创新 = 没有创新；每条超过两行 = 提炼失败。真创新一句话能说清，说不清就回炉。
4. **自引克制，他引充分**：立项依据只引自己圈子 = 视野窄；国内外现状要有他组工作的正面引用并说明"他们做到了哪、还差哪"。
5. **技术路线图是本子的脸**：一张逻辑闭环的路线图胜过三页文字；图中元素与"研究内容"逐条对应，评审人会拿图反查内容。
6. **年度计划要留余量**：三年计划排满 = 任何意外都会击穿进度；第一年安排预试验/方法验证类工作，第三年只排数据补齐与总结。
7. **AI 使用要披露**：申请书里 AI 参与的内容（文献梳理、语言润色、图表生成）按基金委当年规定如实披露——走 `labmate-disclosure` 的声明模板，隐而不报的风险远大于披露本身。

## 与 LabMate 工具链的配合

| 环节 | 工具 | 用法 |
|---|---|---|
| 立项依据现状侦察 | `labmate_search` | 多源聚合查国内外近 3 年进展，按年份过滤；`labmate_arxiv` 补预印本 |
| 文献精读与缺口确认 | `labmate_pdf` + `labmate-literature` | 竞争对手论文本地精读，缺口从"他们没做什么"里长出来 |
| 样本量与试验设计 | `labmate_stats`（power）+ `labmate_doe` | 方案里写"每组 n=X（功效 0.8，α=0.05）"比"若干组"硬一个量级 |
| 方案关键算例 | `labmate_handcalc` | 载荷—应力、围压量级等关键数字先校核再写进方案，杜绝拍脑袋数字 |
| 技术路线/预期成果图 | `labmate_plot` | SVG 出图嵌入申请书；测试方案类曲线（预期载荷—位移）画出来 |
| 预期测量不确定度 | `labmate_errors` | 测量方案的 GUM 合成进方案，显专业功底 |
| 交初稿给合作者 | `labmate_docx` | 不写 LaTeX 的合作者/单位科研处要 Word 版；参考文献用 `labmate_bibtex`（gb7714）出 |
| 交稿前合规 | `labmate-disclosure` | 四类交付前校验 + AI 使用声明 |

## 边界（什么问题要说"超界"）

- 评审运气、当年指南细则、依托单位名额与限项政策——不预测不代答，引导用户查当年正式指南
- 不代写学术内容：工具与协议负责**结构与论证质量**，科学思想必须是用户自己的
- 超出力学/物理相邻领域的专业判断（临床、社科类项目）诚实说明并按通用写作原则引导
