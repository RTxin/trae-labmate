# LabMate · 振动（labmate-vibration）

> 覆盖场景：振动/噪声时程数据的采样方案制定、频谱解读、固有频率与阻尼的试验识别。

依赖：**无新增依赖**——FFT 已内置于 `labmate_signal`（action=spectrum，radix-2 零依赖实现，非二次幂自动零填充并明示）。

## 核心任务与标准做法

| 任务 | 方法/工具 | 要点 |
|---|---|---|
| 采样方案制定（fs 多大、采多久） | 采样定理 + `labmate_signal` spectrum | fs ≥ 2×最高关心频率（Nyquist），工程习惯 2.56×（给抗混叠滤波器留过渡带） |
| 频谱分析 / 找主频 | `labmate_signal` action=spectrum | 给 y 数组 + fs；输出 Δf、Nyquist、直流、主峰（单边幅值谱） |
| 固有频率识别（锤击/自由衰减） | spectrum 主峰 | 自由衰减信号的谱峰即固有频率；多峰 = 多阶模态 |
| 频率分辨率不够 | 延长采样时间 | Δf = fs/N = 1/T，想分辨 1 Hz 必须采够 1 s——是时长问题不是点数问题 |
| 信号去噪 | `labmate_signal` action=smooth | SG 保峰形（频谱前用 ma 会把峰也抹平） |
| 阻尼比估计（半功率带宽） | spectrum 峰两侧找 0.707 幅值点 | ζ = Δf₀.₇₀₇/(2fₙ)；需要足够细的 Δf，否则误差大 |
| 频谱曲线进论文 | `labmate_plot` | spectrum 输出的峰位/幅值表喂给 plot（scatter/line），加图例与轴标签 |

## 代码模板

```json
// 黄金用例：合成 y = sin(2π·50t) + 0.5·sin(2π·120t)，fs = 512 Hz，N = 512（1 秒整周期）

  "arguments": {
    "action": "spectrum",
    "fs": 512,
    "y": [ /* 时程数组，等间距采样 */ ]
  }
}
```

## 本领域的专业常识（模块的灵魂，认真写）

1. **混叠不可逆，采样前必须想清楚**——高于 fs/2 的频率会折叠成低频假峰（例如 fs=1000 Hz 时 600 Hz 信号出现在 400 Hz 处）。混叠发生后**没有任何算法能事后修复**：必须在采集卡/传感器前端用硬件抗混叠滤波。看到疑似"奇怪的低价频"先查混叠，再怀疑结构。
2. **频率分辨率是"试验时长"问题**——Δf = fs/N = 1/T。想分辨相距 1 Hz 的两个峰必须采 1 秒，与采样率多高无关。零填充（工具会明示）只是插值，不增加真实分辨率：它让谱线变密，但区分不出原本分不开的峰。
3. **泄漏与整周期**——信号截断非整周期时能量摊到相邻 bin（幅值偏低、峰位略偏）。能整周期采样（频率是 Δf 整数倍）最好；不能就接受少量泄漏（峰位仍可靠），加 Hann 窗可压旁瓣但会拉宽主瓣。
4. **量级参考**——结构一阶固有频率通常几~几百 Hz；机械振动加速度常见 0.1g~几十 g；加速度计灵敏度典型 100 mV/g，IEPE 恒流源 4 mA；采样位数 24 位动态范围约 140 dB。AI 第一反应应能判断"这个数正不正常"。
5. **红线（超界要说）**——多自由度密集模态的完整模态分析（振型、MAC 校验）、变转速阶次跟踪（order tracking）、声强阵列，超出零依赖频谱工具边界，需专业软件（如模态测试系统）或安装科学栈后另行处理，如实告知用户。
